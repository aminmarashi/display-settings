# Display Settings

An Omarchy shell plugin for arranging displays and tuning per-monitor settings from the bar.

The current `0.1.0` release is an interactive UI preview. Dragging displays, moving sliders, choosing scale and refresh-rate options, and configuring Night Light update local preview state only. No system settings are changed yet.

## Preview

- Select a display from the visual arrangement.
- Drag displays into a new arrangement.
- Zoom the arrangement canvas.
- Change the selected display's brightness, scale, and refresh-rate preview.
- Toggle Night Light and configure its schedule preview.

## Install

```bash
omarchy plugin add https://github.com/aminmarashi/display-settings.git --enable
```

Open **Display Settings** from the `▣` icon in the Omarchy bar.
